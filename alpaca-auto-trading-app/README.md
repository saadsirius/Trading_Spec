# Alpaca Auto-Trading App

## Overview
The Alpaca Auto-Trading App is an automated trading application that leverages the Alpaca API and ChatGPT to provide users with AI-driven trading signals, explanations for each trade decision, and a user-friendly interface. The app supports market scanning, sniping, backtesting, and offers APIs for extended control.

## Features
- **Automated Trading**: Execute trades automatically based on AI-generated signals.
- **Trade Explanations**: Understand the rationale behind each trade with explanations generated by ChatGPT.
- **Backtesting**: Test trading strategies using historical data to evaluate performance.
- **User-Friendly Interface**: Choose between a Flutter mobile app or a React web app for an intuitive user experience.
- **RESTful API**: Access trading functionalities and data programmatically.

## Getting Started

### Prerequisites
- Python 3.8+
- Node.js (for frontend)
- Docker (for containerization)

### Installation

1. **Clone the repository**:
   ```
   git clone https://github.com/yourusername/alpaca-auto-trading-app.git
   cd alpaca-auto-trading-app
   ```

2. **Backend Setup**:
   - Navigate to the backend directory:
     ```
     cd backend
     ```
   - Install dependencies:
     ```
     pip install -r requirements.txt
     ```

3. **Frontend Setup**:
   - For Flutter:
     ```
     cd frontend/flutter_app
     flutter pub get
     ```
   - For React:
     ```
     cd frontend/web_app
     npm install
     ```

4. **Docker Setup**:
   - Build and run the application using Docker:
     ```
     cd docker
     docker-compose up --build
     ```

### Running the Application
- Start the backend server:
  ```
  cd backend/app
  python main.py
  ```
- Launch the frontend application:
  - For Flutter, run:
    ```
    flutter run
    ```
  - For React, run:
    ```
    npm start
    ```
